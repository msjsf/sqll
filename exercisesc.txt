//FLIP THE BIT


You are given a binary array a of length n and k special indices p1,p2,…,pk (1≤pi≤n). It is given that the values ai of all elements at special indices are the same (i. e., ap1=ap2=…=apk).
In one operation, you can choose a range [l,r] (1≤l≤r≤n) such that the range contains at least one special index (l≤pi≤r) and flip all bits aj for l≤j≤r. Flipping a bit changes 0 to 1 and 1 to 0.
Let x denote the value at special indices before any operations are applied. Find the minimum number of operations required to make all elements of the array equal to x.

Tienes que ver bloques, el proceso es ir recorriendo hasta c, que es el indice especial tanto L como R, estos 2 te dan el cambio o fragmentacion de cada bloque,
el lado mas fragmentado es el que te da el resultado por eso se hace max(L, R), el pivot o indice especial tambien se usa de relleno por que se usa como referencia
de x, el cambio de bloque de cada lado es una forma mas estructural de verlo, es un truco con padding y conteo de transiciones pero no es la unica forma.
   

#include <bits/stdc++.h>
using namespace std;

void solve(){
    int n, k, c;
    
    cin>>n>>k;
    
    vector<int>ent(n+2);
    for(int i=1; i<=n; i++)cin>>ent[i];
    
    cin>>c;
    ent[0]=ent[n+1]=ent[c];
    int nl=0, nr=0;
    for(int i=0; i<c; i++){
        if(ent[i]!=ent[i+1])nl++;
        
    }
    
    for(int i=c; i<n+1; i++){
        if(ent[i]!=ent[i+1])nr++;
        
    }
    
    cout<<max(nl, nr)<<endl;//elige el mas fragmentado
    
}

int main() {
    int a, b, c;

    cin>>a;
    while(a--){
        solve();
        
    }
}

Let x denote the value at special indices before any operations are applied. Find the minimum number of operations required to make all elements of the array equal to x.

    j>i,
    pj>pi, and
    qj>qi. 
You are also given an array d of length n, where di denotes the number of indices that dominate index i.
Your task is to construct a permutation q of integers from 1 to n such that for every index i (1≤i≤n), the number of indices j that dominate i is exactly di.
